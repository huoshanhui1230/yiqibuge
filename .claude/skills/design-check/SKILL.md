disable-model-invocation: true
---

要检查的页面：$ARGUMENTS

1. 在 docs/design/README.md 里找到这个页面对应的设计稿：三套主题的 HTML（docs/design/html/<主题>/）和截图（docs/design/png/<主题>/）。
2. 看截图，再读 HTML 里的结构、文案、尺寸、颜色。HTML 里的 `<x-dc>`、`sc-if`、`data-theme-keep` 是设计工具的标记，忽略。
3. 用 H5 预览打开这个页面，三套主题各截一张图。如果还没有 H5 预览，就告诉我，让我在微信开发者工具里截图发给你。
4. 逐条列出和设计稿不一样的地方：缺的元素、文案、间距、字号、颜色、圆角、阴影、插画。区分「需要修」和「有意的改动」。
5. 修掉需要修的地方，再截图确认。最后告诉我还有哪些没改、为什么。

注意：只能用主题变量和组件去还原设计稿，不能为了看起来一样而写死数值。
