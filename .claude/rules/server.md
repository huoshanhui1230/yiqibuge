# 后端和共享包规则

## 时间
- 数据库里的时间全部是 UTC。按群组时区算的东西（周的归属、周一结算、免打扰、相对日）一律用群组的 IANA 时区（如 Australia/Sydney），要考虑夏令时。
- 撤回窗口、鸽值档位都按服务器时间算，不信客户端时间。

## 接口
- 接口列表见 docs/spec.md「核心接口」，路径统一加 /api/v1 前缀。
- 表态接口必须幂等：客户端每次带 request_id。
- 入参用 DTO 校验；错误返回统一格式（code、message），message 用中文。
- 用户身份从云托管 callContainer 注入的用户信息里取 openid（以微信云托管官方文档为准），本地开发用假身份。

## 任务和通知
- 定时和延时任务见 docs/spec.md「定时与延时任务」。每个提醒任务都带计划的 version，执行时 version 不一致就丢弃。
- 订阅消息按「用户 × 模板」记额度，额度紧张时的优先级见 docs/spec.md「订阅消息额度策略」。
- 所有通知同时写进站内通知中心；免打扰时段内的通知延后补发。

## 内容安全
- 群名、昵称、计划标题、详情、鸽了理由在保存前过微信文本内容安全检测；头像和群头像过图片检测。检测接口放在适配器里，本地用假实现。

## 测试
- 鸽值计算、每周评选（含并列、和平周、免鸽卡、回归作废）、表态状态转换、时间文案都要有单元测试，边界情况写全。
