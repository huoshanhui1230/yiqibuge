# 小程序端规则

## 文案
- 品牌名从 `@yiqi/shared` 的 `APP_NAME` 取（值是「一起不鸽」），不在页面里手写。设计稿 HTML 和截图里的「一起恰」是历史名称，走查时不算差异。

## 主题
- docs/design/tokens.json 是唯一的样式来源：生成三套 CSS 变量，挂在页面根节点上，按当前主题切换。
- 组件和页面只用 `var(--yq-*)` 这类主题变量，不写死颜色、圆角、阴影、字体。
- 插画（鸽子、鸽子头套、皇冠、鸽屎、火锅等）每套主题各一份 SVG，从设计稿 HTML 的 `<symbol>` 里取，放在 `src/static/themes/<主题>/`。
- 主题只影响当前用户自己看到的样子；分享到群的卡片配图按分享人的主题画。

## 尺寸和交互
- 设计稿按 390 宽画，换算成 rpx 时乘 750/390（约 1.92）。
- 可点区域不小于 44×44（设计稿尺寸）。
- 文字对比度不低于 4.5:1；清爽风主按钮是 #D6391D 配白字。
- 动效（鸽屎、揭晓、两清章）都要能被「设置 › 动效开关」关掉。

## 表态和时间
- 跟了、不跟、鸽了、撤回都走同一个确认卡组件，必须展示的信息见 docs/spec.md「确认卡必须展示的信息」。
- 按钮上的时间、列表里的时间、倒计时全部调用 packages/shared 的时间文案函数，不在页面里拼日期。

## 平台
- 用 uni.* 接口；只有微信才有的能力（callContainer、订阅消息、分享、头像昵称填写）放在 `src/platform/` 的适配器里，H5 预览时用假实现。
- 不用的接口不要调用；用到头像昵称、选择位置、保存图片等隐私接口时，要和小程序后台的用户隐私保护指引一致。
