# 时间文案（阶段 2 实现）

这里放相对日、时段、倒计时的文案函数。页面和通知里**不手写日期格式**，一律调这里。

实现前先按 `docs/spec.md`「时间文案规则」把测试用例写全，确认测试失败再写实现：

- 今天、明天、后天、本周 X、下周 X、周 X
- 六个时段
- 跨天活动
- 倒计时四档
- 群时区和手机时区不同时多加一行「你的当地时间」
- 跨年
- 悉尼夏令时切换那天

时区用群组的 IANA 时区（如 `Australia/Sydney`），底层用 `luxon`。

`eslint.config.mjs` 里禁止了 `toLocaleDateString` / `Intl.DateTimeFormat`，**只有这个目录例外**——它就是那条规则的实现方。
